# VJK — Supabase-style Backend

Self-hostable backend platform inspired by Supabase, with PostgreSQL, JWT auth, REST APIs, storage, realtime, and an admin dashboard.

## MVP
- PostgreSQL
- Email/password JWT authentication
- REST API
- API-key protection
- Storage API
- WebSocket realtime
- Admin dashboard
- Docker deployment

This is an independent implementation and does not copy Supabase hosted infrastructure or branding.
